# Advanced Database Systems Portfolio

## MIT 8103 — Advanced Database Systems

**Case Study:** University Student Result Management System

## 1. Project Overview

This project develops a database system for managing student academic records in a university. The system is designed to demonstrate practical knowledge of database design, SQL query processing and optimisation, transaction management, NoSQL data modelling, and distributed and cloud databases.

The project will use a consistent university case study across all five portfolio activities.

## 2. Organisation and Database Requirements

The University Student Result Management System is a simulated university information system designed to manage academic activities and student records.

### Main Users
- Students
- Lecturers
- Department administrators
- Academic records officers

### Major Data to Be Stored
- Student information
- Departments and courses
- Lecturer information
- Course registrations
- Semester records
- Examination scores and grades

### Key Database Operations
- Register students for courses.
- Store and retrieve examination scores.
- Calculate grades and semester GPA.
- Generate student academic reports.
- Maintain data integrity and consistency.
- Optimise queries for efficient retrieval.
- Explore NoSQL and distributed database solutions.

## 5. Technologies and Tools

The project will use PostgreSQL for relational database implementation, SQL for querying and transaction management, MongoDB or an equivalent document database for NoSQL modelling, GitHub for version control, and suitable tools for database diagrams and performance analysis.

The final selection and configuration of tools will be documented as the project progresses.

## 6. Testing and Evidence
