## 1. Project Overview

This project develops and documents a database system for managing student academic records in a university. It demonstrates practical knowledge of database design and modelling, SQL query processing and optimisation, transaction management, NoSQL data modelling, and distributed and cloud databases.

The University Student Result Management System is used consistently across the five portfolio activities.

## 2. Organisation and Database Requirements

The University Student Result Management System is a simulated university information system designed to manage academic activities and student records.

### Main Users
- Students
- Lecturers
- Department administrators
- Academic records officers

### Major Data Stored
- Student information
- Departments and courses
- Lecturer information
- Course registrations
- Semester records
- Examination scores and grades

### Key Database Operations
- Register students for courses.
- Store and retrieve examination scores.
- Calculate grades and semester GPA.
- Generate student academic reports.
- Maintain data integrity and consistency.
- Optimise queries for efficient retrieval.
- Explore NoSQL and distributed database solutions.

## 5. Technologies and Tools

The project uses:

- **PostgreSQL:** Relational database implementation and SQL queries.
- **SQL:** Database querying, transaction management, and performance analysis.
- **MongoDB Atlas:** NoSQL document modelling and query implementation.
- **GitHub:** Version control, project documentation, and portfolio hosting.
- **PostgreSQL EXPLAIN and EXPLAIN ANALYZE:** Query plan and performance analysis.
- **MongoDB Atlas Data Explorer:** Document insertion, retrieval, and query testing.
